# Terrain heightmaps

Place tiled or single macro heightmaps here for landscape import.

## Suggested pipeline

1. Generate 16k macro height in Blender, Gaea, or World Machine.
2. Export 16-bit PNG or RAW.
3. UE Landscape Import with scale tuned for Mistspire vertical range (0–8 km simulated).

## Vertical slice shortcut

Use UE **Landscape Mode → Sculpt** with ramp + noise for a 4 km² test without external assets.
