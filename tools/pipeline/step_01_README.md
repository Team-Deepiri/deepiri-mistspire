# Pipeline Step 1 — Create Main_WP Map

Run in UE Editor:
```
Tools → Execute Python Script → tools/pipeline/step_01_create_map.py
```

This creates `Content/Maps/Main_WP` with World Partition enabled, 12 data layers (one per biome), and a PlayerStart at origin.

**Manual fallback:** See `game/Content/Maps/README.md`
