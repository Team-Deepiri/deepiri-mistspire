# Pipeline Step 2 — Sculpt Landscape

1. Open Main_WP
2. Landscape Mode → Create 8129×8129 or import heightmap
3. Scale Z: 100–200× for dramatic vertical strata
4. Position valley at origin, ramp up to 20 km

**Heightmap source:**
- Procedural: Sculpt with noise + ramp brushes
- External: Gaea / World Machine → 16-bit PNG → Landscape Import
